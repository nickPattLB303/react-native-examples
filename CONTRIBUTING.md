# Contributing to the React Native Training Course

Thank you for your interest in contributing to this course! Your input helps improve the learning experience for everyone.

## How to Contribute

We welcome contributions in various forms:

-   **Reporting Issues:** If you find errors (typos, technical inaccuracies, broken links), unclear explanations, or have suggestions for improvement, please [open an issue](link-to-issues-page) in the GitHub repository. Provide as much detail as possible, including the module/lesson name and specific location of the issue.
-   **Suggesting Enhancements:** Have ideas for new topics, exercises, challenges, or better ways to explain concepts? Open an issue to discuss your suggestions.
-   **Pull Requests (For Maintainers/Instructors):** If you are part of the course development team, follow the workflow below. (Direct contributions from learners are typically handled via issues first).

## Development Workflow (For Maintainers)

1.  **Branching:** Create a new branch for your changes, named descriptively (e.g., `fix/typo-module-02`, `feat/add-zustand-example`).
2.  **Make Changes:** Implement your fixes or additions. Adhere to the established `STYLE_GUIDE.md`. Use the provided templates in `/templates` for consistency.
3.  **Preview:** Use the Marp VS Code extension to preview your changes as both documentation and slides.
4.  **Commit:** Write clear and concise commit messages.
5.  **Pull Request:** Open a Pull Request (PR) against the `main` branch. Provide a clear description of the changes made.
6.  **Review:** Another team member should review the PR for accuracy, clarity, and adherence to guidelines.
7.  **Merge:** Once approved, the PR can be merged.

## Style Guide

All contributions should adhere to the guidelines outlined in `STYLE_GUIDE.md`. This includes:

-   Tone and language (Microsoft Writing Style Guide).
-   Formatting (Markdown, Marp directives).
-   Code style (TypeScript, JSDoc, Accessibility).
-   Use of templates and callouts.
-   Mermaid diagram standards.
