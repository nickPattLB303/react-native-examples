Welcome to Module 18, the Capstone Project for the React Native Training Course! This module is where you'll bring together all the knowledge and skills you've acquired throughout the course to build a substantial, real-world-inspired application: SpeedyMeds. Unlike previous modules focused on specific concepts, this module guides you through understanding, developing, and finalizing a comprehensive project. You will work with a pre-configured starter application, focusing on implementing features, UI, and logic based on a defined roadmap.

> 🛣️ **(All Learners):** This module is the culmination of your learning journey. It's designed to simulate a practical development experience, from understanding requirements to implementing features within an existing codebase. Take your time, refer back to previous modules, and enjoy the process of building a complete application.

## Learning Objectives

By the end of this module, you will be able to:

- Analyze and understand the architecture of a pre-configured React Native (Expo) project.
- Navigate and contribute to an existing codebase, adhering to established patterns and conventions.
- Implement UI features based on mockups and requirements using React Native Paper and Styled Components.
- Integrate various React Native concepts, including navigation, state management (Zustand and TanStack Query), theming, and API interactions within a cohesive application.
- Follow a development workflow that includes understanding project scaffolding, data flow, UI implementation, and core feature development.
- Prepare for project evaluation and understand common submission requirements.
- Apply tips for success in completing a capstone-level project.

## Prerequisites

Before starting this module, ensure you have a solid understanding of the concepts covered in all preceding modules (Modules 0-17). Specifically, you should be comfortable with:

- React Native Core Components and APIs (Module 8 & 9)
- Styling with StyleSheet, Flexbox, React Native Paper, and Styled Components (Module 10)
- Navigation with React Navigation and/or Expo Router (Module 11)
- Handling User Input and Forms (Module 12)
- State Management with `useState`, Context API, Zustand, and TanStack Query (Module 13)
- Working with an existing Expo project environment.
- TypeScript and its application in React Native.
- Asynchronous JavaScript and API interactions.

It is highly recommended to have the SpeedyMeds capstone project [SETUP.md](../../SpeedyMeds/SETUP.md) completed and the application running in your development environment.

## Module Sections Overview

This module will guide you through the SpeedyMeds capstone project with the following sections:

- **Section 01: Project Overview and Setup:** Re-iterates the project's goals, tech stack, and initial setup verification.
- **Section 02: Understanding the Project Scaffolding:** Dives into the directory structure and key files of the SpeedyMeds project.
- **Section 03: Data Flow and State Management:** Explains how data is managed using Zustand for client state and TanStack Query for server state, including mock API interaction.
- **Section 04: Navigation Implementation:** Details the navigation structure using React Navigation (Tabs and Stacks).
- **Section 05: UI Layer: Theming and Styling:** Covers how theming (light/dark modes) and styling are implemented with React Native Paper and Styled Components.
- **Section 06: Development Workflow:** Outlines the recommended workflow for tackling features, including setup, debugging, and testing.
- **Section 07: Core Requirements and Milestones:** Presents the checklist of features and functionalities to be implemented (based on `ROADMAP.md`).
- **Section 08: Evaluation and Submission:** Discusses how the project will be evaluated and general submission guidelines.
- **Section 09: Tips for Success:** Offers advice and best practices for successfully completing the capstone project.
