# Section 5: Setting Up Your Learning Environment

A properly configured learning environment is essential for success in React Native development. This section guides you through setting up all the tools and accounts you'll need for the course.

## Overview

You'll need to set up several tools and create accounts for various services. The good news is that most of these are free and widely used in professional development.

> ⚠️ **Important Note:**
>
> Module 3 will cover React Native and Expo-specific setup in detail. This section focuses on general learning tools and accounts you'll need throughout the course.

## Required software

### Code editor

**Visual Studio Code (Recommended)**

VS Code provides excellent React Native development support with extensions for syntax highlighting, debugging, and IntelliSense.

**Installation:**
1. Download from [code.visualstudio.com](https://code.visualstudio.com/)
2. Install using default options
3. Launch and complete the welcome setup

**Essential extensions:**
- React Native Tools
- ES7+ React/Redux/React-Native snippets
- Prettier - Code formatter
- Auto Rename Tag
- Bracket Pair Colorizer

**Alternative editors:**
- WebStorm (paid, comprehensive IDE)
- Atom (free, customizable)
- Sublime Text (lightweight, fast)

### Web browser

**Chrome (Recommended)**

Chrome provides the best debugging tools for React Native development.

**Installation:**
1. Download from [chrome.google.com](https://www.google.com/chrome/)
2. Install and set as default browser
3. Install React Developer Tools extension

**Alternative browsers:**
- Safari (macOS users, good React Native support)
- Firefox (good developer tools)
- Edge (Windows users, modern Chromium-based)

### Terminal application

**macOS:** Terminal (built-in) or iTerm2 (enhanced features)
**Windows:** Command Prompt, PowerShell, or Windows Terminal
**Linux:** Your distribution's default terminal

**Basic terminal skills needed:**
- Navigating directories (`cd`, `ls`/`dir`)
- Creating files and folders (`mkdir`, `touch`)
- Running commands and scripts
- Understanding file paths

## Required accounts

### GitHub account

**Purpose:** Version control, accessing code repositories, and collaboration

**Setup:**
1. Visit [github.com](https://github.com/)
2. Sign up with a professional username
3. Verify your email address
4. Set up two-factor authentication (recommended)

**What you'll use it for:**
- Downloading course materials and examples
- Submitting assignments (if instructor-led)
- Building your portfolio with projects
- Contributing to open-source projects

### Expo account

**Purpose:** React Native development, testing, and deployment

**Setup:**
1. Visit [expo.dev](https://expo.dev/)
2. Sign up with the same email as your GitHub account
3. Verify your email address
4. Complete your profile with professional information

**What you'll use it for:**
- Creating and managing React Native projects
- Testing apps on physical devices
- Building and deploying applications
- Accessing Expo's development tools

### CodeSandbox account

**Purpose:** Web-based development for JavaScript and React exercises

**Setup:**
1. Visit [codesandbox.io](https://codesandbox.io/)
2. Sign up using your GitHub account (recommended)
3. Complete your profile setup

**What you'll use it for:**
- JavaScript and React exercises
- Quick prototyping and experimentation
- Sharing code examples and solutions

## Optional but recommended

### Stack Overflow account

**Purpose:** Getting help with development questions

**Setup:**
1. Visit [stackoverflow.com](https://stackoverflow.com/)
2. Sign up with a professional profile
3. Read the community guidelines
4. Set up tag preferences for React Native, JavaScript, and React

### Discord

**Purpose:** Real-time community support and discussions

**Setup:**
1. Download Discord from [discord.com](https://discord.com/)
2. Create an account with a professional username
3. Join the React Native Community server
4. Set up notification preferences

### Note-taking application

Choose one that works well for you:

**Digital options:**
- Notion (comprehensive, free tier)
- Obsidian (markdown-based, powerful linking)
- OneNote (Microsoft ecosystem integration)
- Apple Notes (macOS/iOS users)

**Traditional option:**
- Physical notebook and pen (proven effective for retention)

## Troubleshooting common issues

### Installation problems

**Issue:** Software won't install due to permissions
**Solution:** Run installer as administrator or use `sudo` on macOS/Linux

**Issue:** Old versions of software already installed
**Solution:** Uninstall old versions before installing new ones

**Issue:** Browser extensions not working
**Solution:** Ensure you're using a supported browser and check extension permissions

### Account problems

**Issue:** Email verification not received
**Solution:** Check spam folder, try a different email address, or contact support

**Issue:** Username already taken
**Solution:** Try variations like adding numbers or using underscores

**Issue:** Two-factor authentication setup issues
**Solution:** Use authenticator apps like Google Authenticator or Authy

## Getting help

If you encounter setup issues:

1. **Check documentation** for the specific tool or service
2. **Search online** for your specific error message
3. **Ask for help** in community forums or Discord
4. **Contact support** for the specific service if needed
