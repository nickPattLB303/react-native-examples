# Module 0: Course Introduction

Welcome to the React Native Training Course! This module provides the foundation for your learning journey, setting expectations, introducing course components, and preparing your learning environment.

## Learning objectives

By the end of this module, you'll be able to:

- Understand the course goals and how they align with your career objectives
- Identify your learning path based on your background and goals
- Navigate the course structure and use all learning tools effectively
- Set up your development environment for optimal learning

## Prerequisites

This course assumes you have:

- Basic programming experience in any language
- Familiarity with command-line interfaces
- A computer capable of running development tools (macOS, Windows, or Linux)

No prior experience with React Native, React, or mobile development is required.

## Module structure

This module contains the following sections:

1. **Welcome and Course Goals** - Understanding what you'll achieve
2. **Target Audience and Prerequisites** - Confirming you're ready to begin
3. **How to Use This Course** - Learning paths and course navigation
4. **Course Components and Terminology** - Understanding exercises, challenges, and resources
5. **Setting Up Your Learning Environment** - Preparing for hands-on learning

## Time commitment

- **Estimated time:** 2-3 hours
- **Hands-on activities:** 1 hour
- **Reading and video:** 1-2 hours
