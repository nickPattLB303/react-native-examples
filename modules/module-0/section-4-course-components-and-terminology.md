# Section 4: Course Components and Terminology

Understanding the course structure and terminology will help you navigate the learning materials effectively and know what to expect from each type of activity.

## Course terminology

### Core concepts

**Module:** A major topical unit covering a specific area of React Native development. Each module contains multiple sections and typically takes 3-6 hours to complete.

**Section:** A subdivision within a module focusing on a specific concept or API. Sections are designed to be completed in 30-45 minutes.

**Exercise:** Short, focused practice activities designed to reinforce specific concepts. Exercises typically take 15-20 minutes and have clear, measurable outcomes.

**Challenge:** More complex applications of concepts that require creative problem-solving. Challenges take 30-60 minutes and often combine multiple concepts.

### Technical terms

**React Native:** The cross-platform mobile development framework we'll be learning. It allows you to build native mobile apps using React and JavaScript.

**Expo:** The platform and toolset we'll use for React Native development. Expo simplifies setup, development, and deployment.

**Component:** Reusable UI building blocks in React Native. Components can be Core Components (provided by React Native) or Custom Components (created by developers).

**Props:** Properties passed from parent components to child components to customize their behavior and appearance.

**State:** Data managed within a component that can change over time, triggering re-renders when updated.

**Hook:** Functions that let functional components use state and other React features. Examples include `useState`, `useEffect`, and `useContext`.

**JSX:** JavaScript XML syntax that allows you to write HTML-like code within JavaScript. It's the standard way to describe UI in React Native.

**Native Modules:** Platform-specific code (iOS/Android) that can be accessed from JavaScript to extend React Native's capabilities.

## Activity instructions

### Reading exercises

1. **Read actively:** Take notes and ask questions as you read
2. **Test examples:** Run and modify all code examples
3. **Relate concepts:** Connect new information to your existing knowledge
4. **Practice explaining:** Summarize concepts in your own words

### Hands-on exercises

1. **Read completely:** Understand the entire exercise before starting
2. **Follow steps:** Complete each step before moving to the next
3. **Test frequently:** Verify your code works at each stage
4. **Experiment:** Try variations and modifications
5. **Debug carefully:** Read error messages and fix issues methodically

### Challenge activities

1. **Plan first:** Outline your approach before coding
2. **Break down:** Divide complex problems into smaller steps
3. **Iterate:** Build incrementally and test frequently
4. **Seek help:** Use resources when genuinely stuck
5. **Review solution:** Compare your approach with provided solutions
