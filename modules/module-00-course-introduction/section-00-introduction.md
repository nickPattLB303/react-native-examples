# Module 0: Course Introduction

![Banner for the React Native Training Course showing React and Expo logos](./assets/images/module-0/course-introduction-banner.png)

This banner visually introduces the course, featuring key technologies you'll master.

Welcome to the React Native Training Course! This introductory module will set you up for success by explaining the course structure, learning paths, tools, and environment setup required. Before diving into React Native development, it's crucial to understand how to navigate this course and prepare your development environment properly.

This module is foundational for all learners. Whether you're coming from native mobile development (Android or iOS) or web development (React, Angular, or other frameworks), this module will provide the essential starting information. Later modules will include specific "Background Bridge Notes" to help connect new React Native concepts to your existing knowledge base.

This diagram provides a visual roadmap of your learning journey throughout this React Native Training Course. It begins with **Module 0: Course Introduction** (your current position, highlighted for clarity), which lays the essential groundwork. From there, you'll progress sequentially through key stages: **Module 1** explores the broader **Landscape of Mobile Development**, followed by **Module 2** which delves into **React Native Architecture**. **Module 3** focuses on **Environment Setup with Expo**. A crucial phase, **Modules 4-7**, covers **Prerequisites** including Web Development Essentials, JavaScript, TypeScript, and React fundamentals, ensuring you have a strong base. The core of your learning happens in **Modules 8-17**, where you'll master **Core React Native Components, APIs, Hooks, Styling, Navigation, State Management, Native Modules, Performance, Publishing, and Advanced Features**. This comprehensive knowledge then culminates in **Module 18: Capstone Project**, where you will apply everything you've learned to build a real-world application, **SpeedyMeds**. Finally, **Module 19: Course Wrap-up** consolidates your learning and outlines next steps for your continued development journey. Each arrow signifies a direct progression, guiding you step-by-step towards React Native proficiency.

## Learning Objectives

By the end of this module, you will be able to:

- Navigate the course structure and materials efficiently
- Identify which learning path (Instructor-Led, Self-Led, or Asynchronous) works best for you
- Set up all required software and tools for the course
- Understand how different developer backgrounds (native iOS, Android, React web, Angular) are accommodated
- Configure your learning environment for accessing course exercises and challenges

## Prerequisites

This module has no prerequisites. It's the starting point for your React Native journey!

> [!NOTE]
> This course is designed for developers with existing programming experience but assumes zero prior knowledge of React Native. If you're completely new to programming, consider first exploring basic web development fundamentals before taking this course.
