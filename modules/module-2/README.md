# Module 2: React Native Architecture Explained

Understanding React Native's architecture is fundamental to becoming an effective developer. This module explores both the legacy bridge architecture and the new architecture, explaining how React Native enables JavaScript code to control native mobile applications.

## Learning objectives

By the end of this module, you'll be able to:

- Explain how the React Native bridge architecture works and its limitations
- Understand the new architecture components: JSI, TurboModules, Fabric, and Codegen
- Compare legacy vs. new architecture benefits and trade-offs
- Understand how rendering works in React Native
- Recognize architectural implications for app performance and development decisions

## Prerequisites

- Completion of Module 1: The Landscape of Mobile Development
- Basic understanding of React concepts (components, state, props)
- Familiarity with JavaScript fundamentals

## Module structure

This module contains the following sections:

1. **Legacy Architecture: The Bridge** - Understanding the original React Native architecture
2. **The New Architecture** - JSI, TurboModules, Fabric, and Codegen
3. **How Rendering Works** - Comparing legacy and Fabric rendering systems
4. **Implications for Developers** - Performance considerations and development practices

## Key concepts covered

- Bridge architecture and threading model
- JavaScript to native communication patterns
- JSI (JavaScript Interface) and synchronous operations
- TurboModules for enhanced native module performance
- Fabric rendering system and its benefits
- Codegen for type safety and interface generation

## Real-world connections

Understanding architecture helps you:

- Debug performance issues and bottlenecks
- Make informed decisions about native modules
- Optimize application performance
- Plan for React Native version migrations
- Evaluate architectural patterns and practices
