# Module 5: JavaScript Essentials for React Native

This module provides a foundational understanding of JavaScript, the language that powers React Native applications. A proficient grasp of modern JavaScript, particularly features introduced in ES6 (ECMAScript 2015) and subsequent versions, is indispensable for developing efficient, maintainable, and robust mobile applications using React Native. By completing this module, you will build the core JavaScript knowledge necessary to effectively work with React and React Native concepts in subsequent modules.

> [!TIP]
> Experienced web developers may find concepts in this section familiar. It's recommended to skim for review, focusing particularly on comparisons drawn to the React Native environment and any differences highlighted in Background Bridge Notes. Native developers new to JavaScript should engage with all content thoroughly, starting from the fundamental principles.

## Learning Objectives

By the end of this module, you will be able to:

- Describe the differences between `var`, `let`, and `const` and choose the appropriate keyword for variable declaration.
- Identify and explain JavaScript's primitive and object data types.
- Utilize various JavaScript operators to perform calculations, comparisons, and assignments.
- Implement control flow using conditional statements (`if`, `else if`, `else`, `switch`) and loops (`for`, `while`, `do...while`, `for...in`, `for...of`).
- Define and invoke functions using different syntaxes (declarations, expressions, arrow functions).
- Explain the concepts of scope, the `this` keyword, and closures.
- Work with objects and arrays, including using methods, destructuring, and spread/rest operators.
- Understand the principles of asynchronous JavaScript and handle asynchronous operations using callbacks, Promises, and `async`/`await`.
- Utilize ES6 module syntax (`import`/`export`) to organize and share code across files.
