# Section 4: React Native Documentation - Exercises

This directory contains exercises for Section 4: React Native Documentation.

## Available Exercises

1. [React Native Documentation Scavenger Hunt](./react-native-documentation-scavenger-hunt/) - A Microsoft Forms scavenger hunt that tests your ability to navigate the React Native documentation efficiently.

## Exercise Types

The exercises in this section are designed to reinforce the concepts covered in the corresponding documentation. They may include:

- **Microsoft Forms Quizzes**: Interactive quizzes to test knowledge and understanding
- **Microsoft Forms Research**: Analysis exercises to apply concepts to real-world scenarios
- **Microsoft Forms Scavenger Hunts**: Exercises to practice finding information in documentation
- **Microsoft Whiteboard Challenges**: Diagramming exercises for visual concepts
- **CodePen Exercises**: Web-based coding exercises
- **Expo Snack Exercises**: React Native coding exercises

Each exercise is designed to take approximately 15-20 minutes to complete.
