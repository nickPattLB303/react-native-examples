# React Native Documentation Scavenger Hunt

This directory contains the materials for the "React Native Documentation Scavenger Hunt" exercise for Section 4: React Native Documentation.

## Exercise Overview

This exercise challenges students to navigate the React Native documentation efficiently and find specific information about components, APIs, and best practices. Using Microsoft Forms, students will complete a series of challenges that require them to locate information in the official documentation and related resources.

## Files Included

- `documentation-scavenger-hunt.md`: Contains the form structure, questions, and evaluation guidance for Microsoft Forms implementation.

## Implementation Instructions

### For Instructors

1. **Create a Microsoft Form**:
   - Log in to Microsoft Forms (https://forms.office.com/)
   - Create a new form using the structure provided in `documentation-scavenger-hunt.md`
   - Configure the form settings as specified in the form configuration section
   - Add appropriate branding and styling as needed

2. **Share with Students**:
   - Share the form link with students through your learning management system
   - Set a deadline for completion if necessary
   - Consider adding the exercise to your course gradebook if applicable

3. **Review Submissions**:
   - Use the evaluation guidance provided in the document to assess student responses
   - Look for evidence of effective search strategies
   - Provide feedback on the quality and accuracy of the information found
   - Consider sharing exemplary responses with the class to demonstrate effective documentation navigation

### For Students

Students should:
1. Access the Microsoft Forms scavenger hunt through the provided link
2. For each challenge, use a different search strategy to find the requested information
3. Record the exact location where they found the information, the search strategy used, and a brief summary
4. Complete the reflection question to synthesize their learning
5. Submit the form within the estimated 15-20 minute timeframe

## Learning Objectives

After completing this exercise, students will be able to:
- Navigate the official React Native documentation effectively
- Identify key sections of the documentation for different needs
- Utilize the API reference to find component and API details
- Discover community resources that complement the official docs
- Apply effective search strategies for finding specific information

## Estimated Time

The exercise is designed to take approximately 15-20 minutes to complete.
