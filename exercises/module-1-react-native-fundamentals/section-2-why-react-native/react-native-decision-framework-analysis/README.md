# React Native Decision Framework Analysis

This directory contains the materials for the "React Native Decision Framework Analysis" exercise for Section 2: Why React Native?

## Exercise Overview

This exercise challenges students to evaluate React Native's suitability for different types of mobile applications. Students will analyze several application scenarios, apply a structured decision framework, and provide recommendations with supporting rationale. This exercise reinforces understanding of React Native's advantages, limitations, and appropriate use cases.

## Files Included

- `react-native-decision-framework-analysis.md`: Contains the form structure, questions, and evaluation guidance for Microsoft Forms implementation.

## Implementation Instructions

### For Instructors

1. **Create a Microsoft Form**:
   - Log in to Microsoft Forms (https://forms.office.com/)
   - Create a new form using the structure provided in `react-native-decision-framework-analysis.md`
   - Configure the form settings as specified in the form configuration section
   - Add appropriate branding and styling as needed

2. **Share with Students**:
   - Share the form link with students through your learning management system
   - Set a deadline for completion if necessary
   - Consider adding the exercise to your course gradebook if applicable

3. **Review Submissions**:
   - Use the evaluation guidance provided in the document to assess student responses
   - Look for evidence of critical thinking and application of concepts
   - Provide feedback on the quality of analysis and recommendations

### For Students

Students should:
1. Access the Microsoft Forms exercise through the provided link
2. Analyze each scenario using the structured decision framework
3. Provide thoughtful recommendations with supporting rationale
4. Complete the reflection questions to synthesize their learning
5. Submit the form within the estimated 15-20 minute timeframe

## Learning Objectives

After completing this exercise, students will be able to:
- Apply a structured framework for evaluating mobile development approaches
- Identify which app features benefit most from React Native's capabilities
- Recognize potential challenges when using React Native for specific requirements
- Articulate the business and technical tradeoffs in cross-platform development decisions

## Estimated Time

The exercise is designed to take approximately 15-20 minutes to complete.
