# Mobile Development Approaches Quiz

This directory contains the materials for the "Mobile Development Approaches Quiz" exercise for Section 1: The Mobile Development Landscape.

## Exercise Overview

This exercise is designed to test students' understanding of different mobile development approaches, their evolution, and the decision-making factors for selecting the appropriate approach for specific scenarios. The quiz covers native, hybrid, and cross-platform development approaches with a focus on React Native.

## Files Included

- `mobile-development-approaches-quiz.md`: Contains the quiz questions, answer choices, correct answers, and additional descriptions for Microsoft Forms implementation.

## Implementation Instructions

### For Instructors

1. **Create a Microsoft Form**:
   - Log in to Microsoft Forms (https://forms.office.com/)
   - Create a new quiz using the questions provided in `mobile-development-approaches-quiz.md`
   - Configure the form settings as specified in the quiz configuration section
   - Add appropriate branding and styling as needed

2. **Share with Students**:
   - Share the form link with students through your learning management system
   - Set a deadline for completion if necessary
   - Consider adding the quiz to your course gradebook if applicable

3. **Review Results**:
   - Use the Microsoft Forms analytics to review student performance
   - Identify common misconceptions or areas where students struggled
   - Consider reviewing these areas in class or providing additional resources

### For Students

Students should:
1. Access the Microsoft Forms quiz through the provided link
2. Complete all questions within the estimated 15-20 minute timeframe
3. Review the explanations for each answer after submission
4. Reflect on how the concepts apply to their own development projects

## Learning Objectives

After completing this exercise, students will be able to:
- Demonstrate understanding of the evolution of mobile development approaches
- Compare and contrast different mobile development strategies
- Apply decision-making frameworks to select appropriate approaches for specific scenarios
- Identify key tradeoffs between performance, development speed, and code sharing

## Estimated Time

The quiz is designed to take approximately 15-20 minutes to complete.
