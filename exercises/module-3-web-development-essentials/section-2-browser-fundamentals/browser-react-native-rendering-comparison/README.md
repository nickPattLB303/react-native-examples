# Browser and React Native Rendering Comparison

This directory contains the materials for the "Browser and React Native Rendering Comparison" exercise for Section 2: How Browsers Work.

## Exercise Overview

In this exercise, students will create a visual comparison of browser rendering and React Native rendering processes to understand their similarities and differences. Using Microsoft Whiteboard, they will diagram both pipelines, highlighting the parallel concepts and architectural differences.

## Files Included

- `example-diagram.md`: Contains a mermaid diagram showing an example of a completed rendering comparison.

## Implementation Instructions

### For Instructors

1. **Set Up Microsoft Whiteboard**:
   - Create a new Microsoft Whiteboard for the class or provide instructions for students to create their own
   - Consider providing a template with basic components already placed to save time
   - Share the whiteboard link with students through your learning management system

2. **Facilitate the Exercise**:
   - Review the example diagram to understand what a complete solution might look like
   - Be prepared to answer questions about specific components of both rendering pipelines
   - Consider doing a brief demonstration of how to start the diagram

3. **Review Student Work**:
   - Look for accurate representation of both rendering pipelines
   - Check that all required components are included and properly labeled
   - Ensure connections between similar concepts are clearly identified
   - Provide feedback on the clarity and completeness of the diagrams

### For Students

Students should:
1. Access Microsoft Whiteboard through the provided link or create a new whiteboard
2. Create a diagram that illustrates both the browser rendering pipeline and React Native's rendering process
3. Include descriptions for each step in both pipelines
4. Highlight similarities and differences between the two approaches
5. Complete the diagram within the estimated 15-20 minute timeframe

## Learning Objectives

After completing this exercise, students will be able to:
- Visualize the complete browser rendering pipeline
- Understand React Native's rendering process
- Identify similarities and differences between the two approaches
- Recognize how these architectural designs affect performance

## Estimated Time

The exercise is designed to take approximately 15-20 minutes to complete.
