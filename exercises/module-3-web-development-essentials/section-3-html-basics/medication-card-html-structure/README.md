# Medication Card HTML Structure

This directory contains the materials for the "Medication Card HTML Structure" exercise for Section 3: HTML Basics.

## Exercise Overview

In this exercise, students will create a semantic HTML structure for a medication card component that displays essential medication information. This exercise focuses on proper HTML structure before adding any styling (which will be covered in the next section).

## Files Included

- `starter-template.html`: A basic HTML template to get started
- `completed-example.html`: A completed example of the medication card HTML structure
- `react-native-comparison.md`: A guide showing how the HTML structure translates to React Native components

## Implementation Instructions

### For Instructors

1. **Set Up CodePen**:
   - Create a new CodePen collection for the class
   - Fork the starter template for students to use
   - Share the CodePen link with students through your learning management system

2. **Facilitate the Exercise**:
   - Review the completed example to understand what a complete solution might look like
   - Be prepared to answer questions about semantic HTML elements
   - Discuss how the HTML structure would translate to React Native components

3. **Review Student Work**:
   - Look for appropriate use of semantic HTML elements
   - Check that all required information is included
   - Ensure proper heading hierarchy and structure
   - Review comments explaining semantic choices and React Native translations

### For Students

Students should:
1. Access the starter template in CodePen
2. Create a semantic HTML structure for a medication card
3. Include all required information (medication name, dosage, schedule, etc.)
4. Use appropriate semantic HTML elements
5. Add comments explaining their choices and React Native translations
6. Complete the exercise within the estimated 15-20 minute timeframe

## Learning Objectives

After completing this exercise, students will be able to:
- Apply semantic HTML elements appropriately
- Create well-structured, accessible HTML
- Organize content in a logical hierarchy
- Understand how HTML structure translates to React Native components

## Estimated Time

The exercise is designed to take approximately 15-20 minutes to complete.
