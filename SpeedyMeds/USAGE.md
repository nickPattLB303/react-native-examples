# Using the SpeedyMeds Application

This document provides guidance on using the SpeedyMeds application developed during the React Native training course.

## Running the Application

To run the application in a development environment (using Expo Go, iOS Simulator, or Android Emulator), please follow the instructions provided in the main [README.md](./README.md) under the "Running the App" section, or the more detailed instructions in [SETUP.md](./SETUP.md).

## Key Features (Overview)

As the application is developed, you will be able to interact with the following core features (based on the mockups in `assets/images/` and the project [ROADMAP.md](./ROADMAP.md)):

- **Dashboard:** Get an overview and navigate to other sections.
- **Prescriptions:** View and manage your medication list.
- **Orders:** Track the status of your medication orders.
- **Account:** Manage your profile and application settings.
