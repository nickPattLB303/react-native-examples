### Added
- Initial project structure with Expo, TypeScript, React Navigation, React Native Paper, Styled Components, Zustand, TanStack Query, ESLint, Prettier, Jest, RNTL.
- Complete setup for core architecture: Navigation, Theming (Light/Dark/System), Global State (Zustand), Server State Caching (TanStack Query), Mock API Simulation.
- Placeholder screen components for Home, Prescriptions, Orders (List & Detail), Account.
- Basic reusable components: LoadingIndicator, ErrorDisplay, ScreenContainer, ThemeSelector.
- Testing infrastructure including Jest setup, custom render function, and basic tests for placeholders and store actions.
- Foundational documentation (README, SETUP, CONTRIBUTING, USAGE, ROADMAP, CHANGELOG).
