# React Native Training Course

Welcome to the comprehensive React Native Training Course! This repository contains all the materials needed to learn React Native development from the ground up, designed for multiple learning paths and developer backgrounds.

## Course Overview

This course is designed to take developers from various backgrounds (Android, iOS, React, Angular) and make them proficient in React Native development. The curriculum follows a modular approach to support different learning paths and is built using the ADDIE model (Analysis, Design, Development, Implementation, Evaluation).

## Learning Paths

### Instructor-Led
- **Duration**: 4 weeks
- **Approach**: Collaborative
- **Includes**:
  - Daily 1-hour instructor-led sessions
  - Self-directed learning
  - Instructor support through Webex
  - Access to Webex channel for collaboration
  - Access to this GitHub repository
  - Access to Confluence documentation

### Self-Led
- **Duration**: Self-paced (designed for 4 weeks)
- **Approach**: Independent learning with collaborative resources upon request
- **Includes**:
  - Self-directed learning
  - Access to Confluence documentation
  - Access to Articulate 360 course
  - Optional instructor support through Webex
  - Optional access to collaboration channels
  - Optional access to this GitHub repository

### Asynchronous
- **Content**: Topic-specific as needed
- **Duration**: Self-determined
- **Includes**:
  - Self-directed learning
  - Access to Confluence documentation
  - Access to Articulate 360 course
  - Optional instructor support through Webex

## Course Structure

The course is divided into 12 modules:

1. **React Native Fundamentals**
   - History of mobile development
   - Why React Native
   - How React Native works under the hood

2. **React Native Environment Setup**
   - Setting up with Expo
   - iOS simulator and Android emulator
   - Project structure overview

3. **Web Development Essentials**
   - HTML basics
   - CSS fundamentals
   - Web concepts relevant to React Native

4. **JavaScript Essentials**
   - Core JavaScript concepts
   - ES6+ features
   - Asynchronous programming

5. **TypeScript Essentials**
   - TypeScript basics
   - Type systems in React Native
   - Advanced typing

6. **React Essentials**
   - Components
   - Props and state
   - Lifecycle methods and hooks

7. **React Native Components and User Input**
   - Core components
   - User input handling
   - Platform-specific components

8. **React Native UI and Styling**
   - StyleSheet API
   - Styled-components
   - Responsive design

9. **Navigation and Routing**
   - Expo Router
   - React Navigation
   - Deep linking

10. **State Management**
    - Context API
    - Zustand
    - React Query (useQuery)

11. **Performance and Debugging**
    - Performance optimization
    - Debugging tools
    - Testing

12. **Advanced Features**
    - Animations
    - Native modules
    - Advanced patterns

Each module includes:
- Comprehensive documentation
- Interactive slides
- Hands-on exercises (15-20 minutes each)
- End-of-module challenges (30-60 minutes each)

All examples, exercises, and challenges follow a pharmacy/medication theme to provide a consistent real-world context.
