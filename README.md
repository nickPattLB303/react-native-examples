# React Native Training Course - Documentation Hub

This repository serves as the central hub and single source of truth for the React Native training course content. The documentation is written in Markdown using [Marp](https://marp.app/) to enable dual use as both readable documentation and presentation slides.

## Purpose

The goal is to provide comprehensive, modular, and engaging learning materials suitable for various learning paths (Instructor-Led, Self-Led, Asynchronous) and accessible through multiple channels (Confluence, Articulate 360, GitHub, Live Sessions).

## Structure

-   `/docs`: Contains the main course content, organized into modules.
    -   `/docs/modules`: Individual topic modules.
-   `/templates`: Reusable Markdown snippets and templates for consistent content structure.
-   `/themes`: Custom Marp theme CSS.
-   `/scripts`: Helper scripts for content creation and maintenance.
-   `COURSE_OUTLINE.md`: Detailed breakdown of modules and lessons.
-   `PLAN.md`: The project plan document.
-   `STYLE_GUIDE.md`: Guidelines for writing and formatting content.
-   `CONTRIBUTING.md`: Information on how to contribute.

## Usage

Refer to `PLAN.md` and `COURSE_OUTLINE.md` for the overall structure and content plan. Use the Marp VS Code extension for previewing slides and documentation.
