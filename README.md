# React Native Training Course Materials

This repository contains the source materials for the comprehensive React Native training course. The content is written in Markdown and designed to be used with Marp for generating slide decks.

## Overview

This course aims to equip developers with the skills needed to build production-ready React Native applications using the Expo ecosystem. It covers fundamental concepts, advanced features, and best practices.

## Structure

The course content is organized into modules within the `/content` directory. Each module covers a specific topic area. Supporting materials like templates, guidelines, and exercises are located in their respective directories.

## Getting Started (for Content Creators)

1.  Clone this repository.
2.  Install the [Marp for VS Code extension](https://marketplace.visualstudio.com/items?itemName=marp-team.marp-vscode).
3.  Review the documents in the `/contributing-guidelines` directory for details on terminology, style, templates, patterns, and automation.
4.  Use the VS Code snippets defined in `.vscode/course.code-snippets` to accelerate content creation.
