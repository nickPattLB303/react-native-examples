# Welcome to the React Native Training Course!

Develop proficiency in building cross-platform mobile applications.

---

## Course Goal

The primary goal of this course is for participants to become **proficient in React Native development**, capable of contributing to production applications upon completion. We aim to equip you with the fundamental knowledge, practical skills, and best practices needed to build high-quality mobile experiences.

---

## Target Audience

This course is specifically designed for developers who are already proficient in at least one of the following areas:

-   **Native Android Development** (Kotlin/Java)
-   **Native iOS Development** (Swift/Objective-C)
-   **Web Development with React**
-   **Web Development with Angular** (or similar modern web frameworks)

We will leverage your existing programming knowledge and bridge the gap to React Native development.

---

## Learning Paths

This course supports multiple learning styles and schedules:

1.  **Instructor-Led (4 Weeks):** Collaborative, paced learning with daily sessions, self-study, instructor support, and group interaction.
2.  **Self-Led (Self-Paced, ~4 Weeks):** Independent learning using course materials, with optional support and collaboration resources available upon request.
3.  **Asynchronous (Self-Determined):** Flexible learning focused on specific topics as needed, using the provided documentation and resources.

> **Note:** Regardless of the path, all materials are designed to be comprehensive. The primary difference lies in the level of direct interaction and pacing.

---

## How to Use These Materials

These materials are built using [Marp](https://marp.app/) and serve a dual purpose:

-   **Documentation:** Readable guides you can browse through (e.g., on Confluence or GitHub).
-   **Presentation Slides:** Viewable as slides for instructor-led sessions or self-review (using the Marp VS Code extension recommended).

**Key Features:**
-   **Modular Content:** Jump to specific topics easily.
-   **Callouts:** Look for specific guidance based on your background (Native Dev, Web Dev) or importance (Note, Tip, Important, Warning).
-   **Hands-On:** Engage with exercises and challenges using Expo Snack or local setup.
-   **Links:** Abundant links to official documentation for deeper dives.

---

## Course Approach

-   **ADDIE Model:** Structured instructional design.
-   **Microsoft Writing Style Guide:** Clear, concise language.
-   **Hands-on:** Real-world examples and practical application.
-   **Collaborative:** Encouraging interaction and knowledge sharing (especially in Instructor-Led path).
-   **Pharmacy Theme:** Examples, exercises, and the capstone project follow a pharmacy/medication theme for consistency.

## Tools & Resources

-   **Expo Snack / CodeSandbox:** For isolated examples/exercises.
