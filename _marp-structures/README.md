# Marp Reusable Structures

This directory contains reusable elements for creating consistent and high-quality Marp-based course content for the React Native training program.

## Directories

*   **`/snippets`**: Contains small, reusable blocks of Markdown/Marp syntax for common elements like callout boxes or presenter notes. Think of these as primitive components.
*   **`/templates`**: Contains pre-defined structures for individual slide types (e.g., title slide, code example slide). Think of these as single screen components.
*   **`/patterns`**: Describes standard sequences of templates used to present information consistently (e.g., introducing a concept, explaining code). Think of these as user flows or composite components.
*   **`/documentation`**: Contains detailed guides, workflows, decision trees, and checklists for using the snippets, templates, and patterns effectively. Start here to understand how to use this system.

Refer to the files within `/documentation` for detailed usage instructions and guidelines.
