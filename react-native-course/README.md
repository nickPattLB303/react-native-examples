# React Native Training Course

This repository contains materials for a comprehensive React Native Training Course designed for developers with backgrounds in Android, iOS, React, or Angular development.

## Course Overview

The course is designed to support multiple learning paths:

- **Instructor-Led**: 4-week program with daily 1-hour sessions and instructor support
- **Self-Led**: Self-paced learning with access to all course materials
- **Asynchronous**: Topic-specific learning on an as-needed basis

## Repository Structure

```
react-native-course/
├── slides/              # HTML slide decks for each module
├── exercises/           # Exercise files and instructions
├── challenges/          # End-of-module challenges
├── documentation/       # Markdown documentation
└── assets/              # Shared assets for slides and documentation
    ├── images/          # Images used in slides and documentation
```

## Using the Slides

The slides are built using HTML, CSS, and JavaScript with [Reveal.js](https://revealjs.com/). They can be viewed in any modern web browser without any additional setup.

### Features

- **Learning Path Toggles**: Switch between Instructor-Led, Self-Led, and Asynchronous content
- **Platform-Specific Toggles**: Show content relevant to your background (Android, iOS, React, Angular)
- **Interactive Examples**: Try out code examples directly in the slides
- **Instructor Notes**: Hidden notes for instructors (visible in presenter mode)

### How to Use

1. Open any HTML file in the `slides/` directory in a web browser
2. Navigate using arrow keys or the on-screen controls
3. Press `ESC` to see an overview of all slides
4. Press `S` to view speaker notes (for instructors)
5. Use the learning path toggles to show content relevant to your learning path
6. Use the platform toggles to show content relevant to your development background

### Customizing Slides

Each module follows the same structure based on the template. To create a new module:

1. Copy `slides/template.html` to a new file (e.g., `slides/module-13-custom.html`)
2. Update the title, module number, and content
3. Add module-specific styles if needed

## Exercises and Challenges

- **Exercises**: Each section includes exercises that take 15-20 minutes to complete
- **Challenges**: Each module ends with a more complex challenge that takes 30-60 minutes

All exercises and challenges follow a pharmacy/medication theme to provide real-world context.
