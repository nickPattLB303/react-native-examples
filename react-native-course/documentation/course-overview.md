# React Native Training Course Overview

## Course Description

This comprehensive React Native Training Course is designed to help developers with backgrounds in Android, iOS, React, or Angular become proficient in React Native development. The course covers everything from fundamentals to advanced topics, with a focus on practical, hands-on learning through exercises and challenges.

## Target Audience

This course is specifically designed for developers with experience in:

- Native Android development
- Native iOS development
- Web development with React
- Web development with Angular

While the course accommodates all these backgrounds, certain sections will be more relevant depending on your experience. The course materials include platform-specific callouts to help you relate React Native concepts to your existing knowledge.

## Learning Objectives

By the end of this course, participants will be able to:

1. Understand the core concepts and architecture of React Native
2. Set up and configure a React Native development environment
3. Create and style React Native components
4. Manage application state effectively
5. Implement navigation and routing in React Native applications
6. Debug and optimize React Native applications
7. Work with native modules when necessary
8. Build production-ready React Native applications
9. Follow best practices for React Native development
10. Understand the React Native ecosystem and community resources

## Course Approach

This course follows the ADDIE model (Analysis, Design, Development, Implementation, Evaluation) and adheres to the Microsoft Writing Style Guide for clear, concise, and accessible content. The approach emphasizes:

- Hands-on, real-world experience
- Fun, friendly, and collaborative learning
- Practical application of concepts
- Progressive skill building

## Course Modules

### Module 1: React Native Fundamentals
- History of mobile development
- Core concepts of React Native
- How React Native works under the hood
- Advantages and limitations of React Native
- Real-world applications and use cases

### Module 2: React Native Environment Setup
- Setting up Expo
- iOS simulator and Android emulator configuration
- Project structure overview
- Understanding the Expo workflow
- Creating and running your first React Native app

### Module 3: Web Development Essentials
- HTML, CSS, and JavaScript basics
- Web concepts relevant to React Native
- The DOM and virtual DOM
- CSS-in-JS paradigm
- Web vs. mobile development considerations

### Module 4: JavaScript Essentials
- Modern JavaScript features (ES6+)
- Asynchronous programming with Promises and async/await
- Functional programming concepts
- Array methods and object manipulation
- Error handling

### Module 5: TypeScript Essentials
- TypeScript basics and benefits
- Type definitions and interfaces
- Generic types
- Type inference and type assertions
- TypeScript with React Native

### Module 6: React Essentials
- Components and props
- State and lifecycle
- Hooks (useState, useEffect, useContext, etc.)
- Context API
- Higher-order components and render props

### Module 7: React Native Components and User Input
- Core components (View, Text, Image, etc.)
- User input handling (TextInput, TouchableOpacity, etc.)
- Platform-specific components
- Form handling and validation
- Keyboard management

### Module 8: React Native UI and Styling
- StyleSheet API
- Styled-components
- Responsive design and device adaptation
- Theming and dark mode
- UI libraries and component kits

### Module 9: Navigation and Routing
- Expo Router
- React Navigation
- Stack, tab, and drawer navigation
- Deep linking
- Authentication flows

### Module 10: State Management
- Context API for global state
- Zustand for simple state management
- React Query for server state
- Data persistence with AsyncStorage
- State management patterns and best practices

### Module 11: Performance and Debugging
- Performance optimization techniques
- Using the React DevTools
- Debugging with Chrome Developer Tools
- Profiling and measuring performance
- Testing strategies

### Module 12: Advanced Features
- Animations with Animated API
- Gesture handling
- Native modules integration
- Push notifications
- Deployment and publishing

## Learning Paths

The course supports three learning paths to accommodate different learning styles and schedules:

### Instructor-Led Path
- 4-week program with daily 1-hour instructor-led sessions
- Supplemented with self-directed learning
- Instructor support through Webex
- Collaborative learning with other developers

### Self-Led Path
- Self-paced learning designed for completion in 4 weeks
- Access to all course materials
- Optional instructor support upon request

### Asynchronous Path
- Topic-specific learning on an as-needed basis
- Focus on specific modules or sections
- Self-determined pace and scope

## Pharmacy/Medication Theme

All examples, exercises, and challenges in this course follow a pharmacy/medication theme. This provides a consistent, real-world context for learning and demonstrates how React Native can be used to build healthcare applications with specific requirements around:

- Data management
- User interfaces
- Notifications and reminders
- Security and privacy
- Accessibility

## Assessment and Evaluation

Progress and learning are evaluated through:

- Completion of module exercises
- Implementation of module challenges
- Code quality and adherence to best practices
- Application of concepts to solve real-world problems

## Course Materials

The course includes:

- HTML slide decks for each module
- Markdown documentation
- Code examples and starter templates
- Exercises with step-by-step instructions
- Challenges with requirements and evaluation criteria
- Links to external resources and official documentation

## Prerequisites

To get the most out of this course, participants should have:

- Proficiency in at least one of the target backgrounds (Android, iOS, React, or Angular)
- Basic understanding of JavaScript
- Familiarity with command-line interfaces
- A computer capable of running development tools
