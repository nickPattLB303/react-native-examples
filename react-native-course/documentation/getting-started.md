# Getting Started with the React Native Training Course

This guide will help you navigate the React Native Training Course materials and get the most out of your learning experience.

## Course Structure

The course is organized into 12 modules, each covering specific aspects of React Native development:

1. **React Native Fundamentals**
2. **React Native Environment Setup**
3. **Web Development Essentials**
4. **JavaScript Essentials**
5. **TypeScript Essentials**
6. **React Essentials**
7. **React Native Components and User Input**
8. **React Native UI and Styling**
9. **Navigation and Routing**
10. **State Management**
11. **Performance and Debugging**
12. **Advanced Features**

Each module contains:
- Slide presentations
- Exercises (15-20 minutes each)
- A challenge (30-60 minutes)
- Documentation and resources

## Learning Paths

The course supports three learning paths:

### Instructor-Led Path

- **Duration**: 4 weeks
- **Format**: Daily 1-hour instructor-led sessions with self-directed learning
- **Support**: Instructor support through Webex chat and huddles
- **Collaboration**: Access to Webex channel for collaboration with other developers
- **Materials**: Access to all course materials including GitHub repo and Confluence documentation

#### Recommended Schedule:
- **Week 1**: Modules 1-3
- **Week 2**: Modules 4-6
- **Week 3**: Modules 7-9
- **Week 4**: Modules 10-12

### Self-Led Path

- **Duration**: Self-paced (designed for completion in 4 weeks)
- **Format**: Independent learning with collaborative resources upon request
- **Support**: Instructor support through Webex chat and huddles (upon request)
- **Materials**: Access to Confluence documentation and Articulate 360 course

#### Recommended Approach:
- Allocate 1-2 hours daily for learning
- Complete exercises and challenges for each module before moving on
- Use the Webex channel to ask questions when needed

### Asynchronous Path

- **Duration**: Self-determined
- **Format**: Topic-specific learning on an as-needed basis
- **Materials**: Access to Confluence documentation and Articulate 360 course

#### Recommended Approach:
- Identify specific topics you need to learn
- Focus on relevant modules and sections
- Complete related exercises to reinforce learning

## How to Use the Materials

### Slides

The slide decks are HTML-based presentations that can be viewed in any modern web browser:

1. Navigate to the `slides` directory
2. Open the HTML file for the module you want to study
3. Use arrow keys to navigate through the slides
4. Press `ESC` to see an overview of all slides
5. Press `S` to view speaker notes (for instructors)
6. Use the learning path toggles to show content relevant to your learning path
7. Use the platform toggles to show content relevant to your development background

### Exercises

Exercises are designed to be completed in 15-20 minutes and focus on specific skills:

1. Navigate to the `exercises` directory
2. Find the exercise for the current module/section
3. Follow the instructions in the markdown file
4. Complete the exercise using your preferred development environment
5. Check your solution against the expected output

### Challenges

Challenges are more comprehensive tasks that integrate multiple concepts:

1. Navigate to the `challenges` directory
2. Find the challenge for the current module
3. Read through all requirements before starting
4. Plan your approach before coding
5. Implement the solution step by step
6. Test your solution thoroughly
7. Review the evaluation criteria to ensure your solution meets all requirements

### Documentation

The documentation provides additional context, explanations, and resources:

1. Navigate to the `documentation` directory
2. Read the relevant documentation for your current module
3. Use the links to access official documentation and additional resources

## Development Environment

This course uses Expo for React Native development. To set up your environment:

1. Install Node.js (version 14 or later)
2. Install Expo CLI: `npm install -g expo-cli`
3. For iOS development: Install Xcode (Mac only)
4. For Android development: Install Android Studio

Detailed setup instructions are provided in Module 2.

## Pharmacy/Medication Theme

All examples, exercises, and challenges in this course follow a pharmacy/medication theme. This provides:

1. A consistent context for learning
2. Real-world scenarios that demonstrate practical applications
3. Examples that showcase important mobile development concepts like data management, notifications, and user input
