# Introduction to Web, JavaScript, and TypeScript Essentials

This module establishes the necessary foundational knowledge in web styling concepts (adapted for React Native), modern JavaScript (ES6+), and TypeScript, which are essential prerequisites for building applications with React Native. It bridges the gap for developers coming from different backgrounds and mandates the use of TypeScript for enhanced code quality.

## Learning Objectives

By the end of this module, you will be able to:

- Identify key CSS concepts (Flexbox, styling properties) relevant to React Native styling
- Master core ES6+ JavaScript features essential for React/React Native development (variables, functions, objects, arrays, async)
- Understand the benefits of TypeScript in large applications
- Apply basic TypeScript types and interfaces to React Native components and props

## Why This Matters

React Native development requires a solid understanding of modern JavaScript and styling concepts. While React Native uses native components rather than HTML/CSS, its styling system is inspired by CSS, particularly Flexbox. Understanding these foundations will help you create well-structured, maintainable applications.

TypeScript adds static typing to JavaScript, which helps catch errors during development rather than at runtime. This is particularly valuable in large applications and team environments. For this course, TypeScript is mandatory for all code examples and exercises to ensure you develop good habits from the start.

## Module Structure

This module is organized into the following sections:

1. **Styling in React Native**: Learn how React Native's styling system differs from web CSS while leveraging familiar concepts like Flexbox
2. **Essential JavaScript (ES6+)**: Master modern JavaScript features crucial for React Native development
3. **Asynchronous JavaScript**: Understand Promises and async/await for handling asynchronous operations
4. **TypeScript Benefits and Basics**: Learn why TypeScript is valuable and how to use its basic features
5. **TypeScript with React Native**: Apply TypeScript to React Native components, props, and state

Let's begin by exploring how styling works in React Native and how it differs from traditional web development.
