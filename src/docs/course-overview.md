# React Native Training Course - Overview

This document provides a comprehensive overview of the React Native Training Course, including its structure, learning paths, and delivery methods.

## Course Goals

The primary goal of this course is to enable developers from various backgrounds (Android, iOS, React, Angular) to become proficient in React Native development. By the end of the course, participants will be able to:

1. Understand React Native fundamentals and architecture
2. Set up and configure a React Native development environment
3. Build responsive and performant React Native applications
4. Implement navigation, state management, and data fetching
5. Debug and optimize React Native applications
6. Apply best practices for production-ready development

## Learning Paths

This course is designed to support multiple learning paths to accommodate different learning styles and schedules.

### Instructor-Led Path

**Duration:** 4 weeks  
**Approach:** Collaborative  
**Includes:**
- Daily 1-hour instructor-led sessions
- Self-directed learning between sessions
- Instructor support through Webex chat and huddles
- Access to Webex channel for collaboration with other developers
- Access to GitHub repository with course materials
- Access to Confluence documentation

**Weekly Structure:**
- Week 1: Modules 1-3 (Fundamentals, Environment Setup, Web Essentials)
- Week 2: Modules 4-6 (JavaScript, TypeScript, React Essentials)
- Week 3: Modules 7-9 (Components, UI/Styling, Navigation)
- Week 4: Modules 10-12 (State Management, Performance, Advanced Features)

### Self-Led Path

**Duration:** Self-paced (designed for completion in 4 weeks)  
**Approach:** Independent learning with collaborative resources upon request  
**Includes:**
- Self-directed learning through documentation
- Access to Confluence documentation
- Access to Articulate 360 course
- Optional instructor support through Webex (upon request)
- Optional access to Webex channel for collaboration (upon request)
- Optional access to GitHub repository with course materials (upon request)

**Recommended Pace:**
- Week 1: Modules 1-3
- Week 2: Modules 4-6
- Week 3: Modules 7-9
- Week 4: Modules 10-12

### Asynchronous Path

**Duration:** Self-determined  
**Content:** Specific topics determined on an as-needed basis  
**Includes:**
- Self-directed learning through documentation
- Access to Confluence documentation
- Access to Articulate 360 course
- Optional instructor support through Webex (upon request)

## Course Structure

The course is divided into 12 modules, each focusing on a specific aspect of React Native development. Each module includes:

- Comprehensive documentation
- Interactive slides
- Hands-on exercises (15-20 minutes each)
- End-of-module challenges (30-60 minutes each)

### Module Overview

1. **React Native Fundamentals**
   - History of mobile development
   - Why React Native
   - React Native architecture
   - Documentation and resources

2. **React Native Environment Setup**
   - Setting up with Expo
   - iOS simulator and Android emulator
   - Project structure overview
   - Expo tools and services

3. **Web Development Essentials**
   - HTML basics
   - CSS fundamentals
   - Web concepts relevant to React Native
   - Web APIs and their React Native equivalents

4. **JavaScript Essentials**
   - Core JavaScript concepts
   - ES6+ features
   - Asynchronous programming
   - Functional programming concepts

5. **TypeScript Essentials**
   - TypeScript basics
   - Type systems in React Native
   - Advanced typing
   - TypeScript best practices

6. **React Essentials**
   - Components and JSX
   - Props and state
   - Lifecycle methods and hooks
   - Component composition

7. **React Native Components and User Input**
   - Core components
   - User input handling
   - Platform-specific components
   - Custom components

8. **React Native UI and Styling**
   - StyleSheet API
   - Styled-components
   - Responsive design
   - Design systems

9. **Navigation and Routing**
   - Expo Router
   - React Navigation
   - Deep linking
   - Navigation patterns

10. **State Management**
    - Context API
    - Zustand
    - React Query (useQuery)
    - State management patterns

11. **Performance and Debugging**
    - Performance optimization
    - Debugging tools
    - Testing
    - Profiling

12. **Advanced Features**
    - Animations
    - Native modules
    - Advanced patterns
    - Production readiness

## Pharmacy/Medication Theme

Throughout the course, all examples, exercises, and challenges follow a pharmacy/medication theme to provide a consistent real-world context. This includes:

- Medication information display
- Prescription management
- Pharmacy locator functionality
- Medication reminders and scheduling
- Drug interaction checking
- Health information resources

This theme provides a rich domain with various data types, user interactions, and real-world constraints that make for effective learning examples.

## Platform-Specific Guidance

The course includes specific callouts for developers coming from different backgrounds:

- **Android Developers:** Parallels to Android concepts, Java/Kotlin to JavaScript/TypeScript transitions
- **iOS Developers:** Parallels to iOS concepts, Swift/Objective-C to JavaScript/TypeScript transitions
- **React Developers:** Differences between React DOM and React Native
- **Angular Developers:** Conceptual mapping between Angular and React/React Native

These callouts help participants leverage their existing knowledge while learning React Native.
