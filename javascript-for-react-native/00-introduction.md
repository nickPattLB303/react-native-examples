# Module 0: Introduction - Modern JavaScript for React Native

**Welcome!**

This module provides a foundational review of modern JavaScript, specifically focusing on the features and concepts most relevant to building applications with React and React Native. A strong grasp of JavaScript is the single most important prerequisite for becoming proficient in React Native development.

**Why JavaScript is Crucial for React Native**

React Native allows you to build native mobile applications using JavaScript and React. While React Native handles the bridge to native components, your application logic, component structure, state management, and interactions are all written in JavaScript. Modern JavaScript (often referred to as ES6, ES2015, and beyond) introduced significant improvements that make code more readable, maintainable, and powerful – features heavily utilized in the React Native ecosystem.

**Learning Objectives**

By the end of this module, you should be able to:

*   Understand the importance of modern JavaScript features for React Native development.
*   Identify the key topics covered in this module.
*   Navigate the module structure and resources effectively.

**Prerequisites**

*   Basic familiarity with programming concepts (variables, functions, basic logic).
*   While not strictly required, some prior exposure to JavaScript (even older versions) can be helpful.

**Module Structure**

This module is divided into the following sections:

1.  **Variables & Scope:** Understanding `let`, `const`, and block scope vs. `var`.
2.  **Data Types:** Primitives and Objects in JavaScript.
3.  **Operators:** Essential operators for manipulation and comparison.
4.  **Control Flow:** Directing the execution flow of your code.
5.  **Functions:** Mastering function declarations, expressions, and arrow functions, including `this`.
6.  **Objects:** Working with object literals, properties, methods, destructuring, and the spread syntax.
7.  **Arrays:** Leveraging key array methods, destructuring, and the spread syntax.
8.  **Asynchronous JavaScript:** Handling asynchronous operations with Callbacks, Promises, and `async/await`.
9.  **Modules:** Organizing code with `import` and `export`.
10. **Conclusion:** Summarizing key takeaways and suggesting next steps.

**How to Use This Module**

*   Read through the sections sequentially for a comprehensive understanding.
*   Pay close attention to code examples, especially those highlighting React/React Native context.
*   Follow the provided links to external documentation (MDN, React Native, React) for deeper dives into specific topics.
*   Experiment with the code snippets yourself, perhaps using an online JavaScript playground or a local Node.js environment.
